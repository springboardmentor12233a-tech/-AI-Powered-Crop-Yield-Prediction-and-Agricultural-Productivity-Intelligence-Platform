YIELDSENSE AI
UI WIREFRAME

1. LOGIN PAGE

Purpose:
Allow registered users to securely access the YieldSense AI platform.

Components:
- Project logo/name
- Email input
- Password input
- Login button
- Error message area

Flow:
Login → Dashboard


2. DASHBOARD

Purpose:
Provide an overview of agricultural information and prediction activities.

Components:
- Navigation bar
- Total farms
- Total crop records
- Recent predictions
- Average predicted yield
- Yield summary charts
- Navigation to prediction page


3. CROP YIELD PREDICTION PAGE

Purpose:
Allow the user to enter agricultural information and request a crop-yield prediction.

Input fields:
- Region
- Crop type
- Soil moisture
- Soil pH
- Temperature
- Rainfall
- Humidity
- Sunlight hours
- Irrigation type
- Fertilizer type
- Pesticide usage
- Total growing days
- NDVI index
- Crop disease status

Action:
- Predict Yield button


4. PREDICTION RESULT PAGE

Purpose:
Display the predicted crop yield generated by the ML model.

Components:
- Predicted yield (kg/hectare)
- Model used
- Prediction date
- Prediction summary
- Agricultural recommendations


5. AGRICULTURAL INSIGHTS PAGE

Purpose:
Provide useful insights based on crop, environmental and agricultural factors.

Components:
- Crop performance
- Regional yield comparison
- Irrigation comparison
- Fertilizer comparison
- Yield trends
- Agricultural recommendations


6. NAVIGATION

Main navigation:

Login
  ↓
Dashboard
  ↓
Crop Yield Prediction
  ↓
Prediction Result
  ↓
Agricultural Insights


7. RESPONSIVE DESIGN

The interface will be designed to work on:
- Desktop
- Tablet
- Mobile
