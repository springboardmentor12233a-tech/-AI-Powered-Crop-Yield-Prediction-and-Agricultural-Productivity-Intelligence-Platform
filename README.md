# AI-Powered Crop Yield Prediction and Agricultural Productivity Intelligence Platform

## Project Overview

This project is an AI-powered agricultural platform designed to analyze farming data and support crop yield prediction and agricultural decision-making.

The system uses information such as soil conditions, weather conditions, crop details, irrigation, fertilizer usage, and other agricultural factors to generate useful insights.

## Objectives

- Analyze agricultural and environmental data
- Perform Exploratory Data Analysis (EDA)
- Identify important factors related to crop yield
- Build machine learning models for crop yield prediction
- Analyze soil and weather conditions
- Provide agricultural insights and recommendations
- Develop an intelligent platform for farmers

## Dataset

The project uses the following datasets:

- `Smart_Farming_Crop_Yield_2024.csv`
- `YieldSense_AI_Dataset_Collection.xlsx`

The main dataset contains **500 rows and 22 columns**.

### Target Variable

`yield_kg_per_hectare`
