# AI AgriYield Predictor & Advisory Dashboard

Welcome to my **AI AgriYield Predictor** project! I built this full-stack Machine Learning and Generative AI application to explore advanced agricultural forecasting. This system predicts crop yields based on environmental factors and generates tailored agronomic advice using large language models.

---

## 🚀 How to Run the App

I set this up to be incredibly simple to run using a single master script.

### Prerequisites
- Python 3.10+
- Node.js & npm (v18+)
- A Google Gemini API Key

### Step 1: Set up the Environment Variables
In the root directory of this project, create a `.env` file and add your Gemini API key:
```env
GEMINI_API_KEY=your_actual_gemini_api_key_here
```

### Step 2: Start the Servers
Open your terminal in the project root and execute the runner script I wrote:
```bash
python run.py
```
*This command automatically spins up the FastAPI Backend (Port 8000) and the Vite React Frontend (Port 5173) simultaneously.*

### Step 3: Access the Dashboard
Once the servers are running, open your web browser and navigate to:
**[http://localhost:5173](http://localhost:5173)**

## 🎯 How to Use the App

1. **Input Field Parameters:** On the left side of the dashboard, enter the categorical data (State, Crop, Soil Type, Fertilizer) and numerical data for the field (Nitrogen, Phosphorus, Potassium levels, Soil pH, Rainfall, and Temperature).
2. **Generate Forecast:** Click the **"Generate Forecast & Advisory"** button.
3. **Analyze Results:** The right side of the dashboard will update with:
   - **The Forecasted Yield** (in kg/acre) generated instantly by my Random Forest champion model.
   - **The LLM Advisory Report**: A beautifully formatted Markdown response generated by the Gemini Agent, benchmarking the yield, offering soil remediation advice based on Liebig's Law of the Minimum, and suggesting climate stress mitigation tactics.

## 🏗️ What I Implemented (Architecture)

I built this project following a structured 4-module blueprint to handle everything from data engineering to frontend UI:

### 1. Machine Learning & GridSearch Pipeline
- I expanded the agricultural dataset to **9,000 rows** using synthetic data augmentation, adding features like Humidity, Solar Radiation, and Irrigation Methods to increase model robustness.
- I applied an `np.log1p` transformation to the target variable (`Yield_kg_per_acre`) to correct right-skewness, which is common when dealing with cash crop variances.
- I used `GridSearchCV` (5-Fold CV) to evaluate Ridge, Random Forest, and Gradient Boosting models. After training, I serialized the champion model (Random Forest), standard scaler, and one-hot encoded columns via `joblib`.

### 2. Predictive Analytics Concepts
- I integrated core agronomic concepts into the advisory generation, ensuring the LLM understands target variance stabilization and how *Liebig's Law of the Minimum* defines the non-linear relationship between soil pH and NPK nutrient availability.

### 3. Backend API & LLM Agent
- I built a high-performance **FastAPI** server that intercepts API requests, aligns categorical features to the training dimensions, applies standard scaling, and predicts the exact yield.
- I integrated the **google-genai** SDK so my backend can pass the feature matrix and predicted yield into an advanced prompt architecture I designed, returning a structured markdown advisory plan.

### 4. Premium React Dashboard
- I engineered a single-page application (SPA) using **React (Vite)**, **Tailwind CSS**, and **Lucide React**.
- I designed the UI with a sleek, modern glassmorphism aesthetic featuring deep Slate, Emerald, and Cyan gradients to deliver a premium user experience.

## 🔍 Core Code Explanation

Here is a high-level overview of how I structured the primary files in this repository:

### `train_model.py` (The ML Pipeline)
1. **Data Loading & Target Transformation:** Reads the dataset, drops negative/NaN targets, and calculates `y = np.log1p(Yield)` to stabilize the model.
2. **Feature Preprocessing:** Separates numerical and categorical columns. Applies `StandardScaler` to numeric features and `pd.get_dummies` to categorical ones.
3. **GridSearchCV:** Uses 5-fold cross validation across Ridge, RF, and GB models to find the optimal hyperparameters.
4. **Evaluation & Artifact Persistence:** Transforms the log predictions back to raw kilograms using `np.expm1`. Uses `joblib.dump` to permanently save the model, scaler, and columns for live inference.

### `advisory_service.py` (The GenAI Integration)
1. **Environment Setup:** Loads the API keys using `dotenv` and initializes the `genai.Client()`.
2. **Prompt Engineering:** Constructs an agronomic prompt inserting the exact soil metrics and the predicted yield. It strictly enforces a 4-section Markdown format (Yield Benchmarking, Soil Health, Climate Stress, Field Actions).
3. **Execution:** Dispatches the prompt to the `gemini-2.5-flash` model and returns the text response.

### `app.py` (The FastAPI Backend)
1. **Setup & Middleware:** Initializes the FastAPI app with `CORSMiddleware` to allow communication with the React frontend.
2. **Loading Artifacts:** Loads the pre-trained `champion_model`, `scaler`, and `model_columns` from disk at startup.
3. **`/api/predict` Route:**
   - Validates incoming JSON payloads using a Pydantic model.
   - Applies the exact same one-hot encoding and standard scaling logic I used during training, padding any missing categorical columns with `0`.
   - Generates the yield prediction (`np.expm1`), passes it to my `advisory_service.py`, and returns both to the frontend.

### `frontend/src/App.jsx` (The UI Component)
1. **State Management:** Uses React `useState` to track user inputs, loading states, errors, and the final API result.
2. **The `fetch` Call:** POSTs the JSON payload to the FastAPI backend when the user submits the form.
3. **Render Logic:** Displays the HTML forms on the left (styled with Tailwind frosted glass utilities) and conditionally renders the Markdown string returned from the GenAI backend on the right using `<ReactMarkdown>`.

## 🛠️ Complete Setup from Scratch

If you have **only** Python and Node.js installed on your system, run these exact commands to get everything working:

### 1. Install Python Backend Dependencies
Open your terminal in the root directory of the project and run:
```bash
pip install fastapi uvicorn pandas numpy joblib pydantic google-genai python-dotenv
```
*(Optional: You can create a virtual environment first using `python -m venv venv` and activate it: `venv\Scripts\activate` on Windows).*

### 2. Install Node.js Frontend Dependencies
Navigate to the frontend directory and install the required npm packages:
```bash
cd frontend
npm install
cd ..
```

### 3. Setup Environment Variables
If you haven't already, create a `.env` file in the root directory and add your Gemini API key:
```env
GEMINI_API_KEY=your_actual_gemini_api_key_here
```

### 4. Start the Application
Execute the runner script from the root directory to spin up both the FastAPI backend and Vite React frontend:
```bash
python run.py
```
